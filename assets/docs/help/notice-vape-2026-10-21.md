원활한 서비스 이용을 위해 아래 내용을 확인하시고, 종료일 이전에 새 콘솔로의 이용 전환을 준비해 주시기 바랍니다.

<Highlight text="1. 서비스 종료 일정" />

서비스 종료일 이후에는 구 콘솔에 접속하실 수 없으니 이용에 참고해 주시기 바랍니다.

- **종료일: 2026년 12월 31일**
- **종료 내용: 구 콘솔 로그인 및 서비스 이용 종료**

<Highlight text="2. 새 콘솔 이용 안내" />

서비스 종료일 이후에는 아래 새 콘솔을 이용해 주셔야 하며 원활한 서비스 이용을 위해 종료일 이전에 새 콘솔에 접속하시어 기존에 이용하시던 기능을 미리 확인해 주시기 바랍니다.

- **새 콘솔 바로가기: <https://admin.portone.io/>**

<Highlight text="3. 네이버페이 구매평 조회 안내" />

기존 구 콘솔에서 제공하던 네이버페이 구매평 조회 화면은 서비스 종료와 함께 제공이 중단될 예정입니다.

이후 구매평은 API를 통해서만 조회하실 수 있으니, 해당 기능을 이용하시는 고객님께서는 아래 API를 참고해 주시기 바랍니다.

- API: 네이버페이 구매평 조회 API
- Method: GET
- Endpoint: /naver/reviews
- 참고 링크 : <https://developers.portone.io/api/rest-v1/pg.naverpay?v=v1#get%20%2Fnaver%2Freviews>

항상 포트원을 이용해 주셔서 감사드리며, 앞으로도 더 나은 서비스를 제공하기 위해 노력하겠습니다.
